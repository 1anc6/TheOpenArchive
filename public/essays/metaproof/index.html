MetaProof: Evidence-Based Authenticity Analysis for Images

By Lanchenba Mutum · 2026 · Added 20 October 2026NEW

The full write-up of MetaProof, a web app I built that checks an image's metadata, file structure, C2PA Content Credentials, hidden watermarks and pixels, then explains whether it is likely authentic, edited, AI-generated or inconclusive.

Wrongly calling a real photo fake is the costlier mistake. So missing data is never held against a file, the detector's score only decides a verdict on its own when it is very high, signed proof (C2PA) outranks statistical guesses, and when the evidence is weak the answer is inconclusive.
